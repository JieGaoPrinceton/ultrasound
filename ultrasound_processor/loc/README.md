# loc 模块说明

该目录包含一组用于微泡定位的示例脚本。每个脚本都先合成一幅包含微泡的超声图像，再使用不同的滤波/分割/峰值检测策略估计微泡位置，并可视化真实位置与检测结果。

## 文件说明

### loc_1.py
- 方法：高斯滤波 + 局部最大值检测（`peak_local_max`）。
- 主要步骤：
  1. 生成随机微泡点并加入噪声。
  2. 使用高斯滤波模拟PSF平滑。
  3. 通过局部峰值检测得到候选微泡坐标。
  4. 可视化真实位置与检测结果。
- 适用场景：点状目标明显、噪声较低时的快速定位。

### loc_2.py
- 方法：与 loc_1.py 相同（高斯滤波 + 局部最大值检测）。
- 说明：此脚本与 loc_1.py 逻辑一致，属于同一定位策略的重复实现或备份版本。

### loc_3.py
- 方法：高斯滤波 + 最大值滤波（`maximum_filter`）检测局部峰值。
- 主要步骤：
  1. 生成随机微泡点并加入噪声。
  2. 高斯滤波平滑图像。
  3. 使用最大值滤波找到局部极大且强度超过阈值的位置。
  4. 可视化结果。
- 特点：不依赖 `skimage.feature.peak_local_max`，用纯数值操作实现峰值检测。

### loc_4.py
- 方法：中值滤波 + 最大值滤波检测局部峰值。
- 主要步骤：
  1. 生成随机微泡点并加入噪声。
  2. 使用中值滤波抑制椒盐噪声。
  3. 最大值滤波寻找局部峰值。
  4. 可视化结果。
- 适用场景：噪声中包含离群点（椒盐噪声）时的定位。

### loc_5.py
- 方法：中值滤波 + 高斯滤波 + 自适应阈值 + 连通域分析。
- 主要步骤：
  1. 生成高斯形状微泡并加入较低噪声。
  2. 中值滤波抑噪，高斯滤波平滑。
  3. 基于均值与标准差的自适应阈值得到二值图。
  4. 连通域分析并以区域质心作为微泡位置。
- 特点：通过阈值与区域面积约束减少误检，更接近“分割+质心”的定位流程。

### loc_6.py
- 方法：Canny 边缘检测 + Otsu 阈值 + 形态学处理 + 连通域分析。
- 主要步骤：
  1. 生成高斯形状微泡并加入噪声。
  2. Canny 边缘检测并填充区域（用于形态辅助）。
  3. Otsu 阈值得到二值图。
  4. 形态学闭运算、去除小目标。
  5. 连通域分析得到质心位置。
- 特点：结合边缘与阈值分割，更适用于轮廓明显或对形态操作有需求的场景。

## 依赖
- numpy
- matplotlib
- scipy
- scikit-image

## 运行示例
```bash
python loc/loc_1.py
python loc/loc_3.py
python loc/loc_5.py
```

每个脚本都会弹出可视化窗口，左侧显示合成的原始图像，右侧显示检测到的微泡位置。
