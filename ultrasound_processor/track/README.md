# track 模块说明

该目录包含微泡跟踪的示例脚本。整体流程为：合成多帧微泡图像 -> 滤波与阈值化 -> 提取候选微泡位置 -> 采用匹配或聚类策略进行跨帧关联 -> 可视化并导出 GIF。

## 文件说明

### tracking_1.py
- 方法：阈值分割 + 连通域质心 + 匈牙利算法（最小距离匹配）。
- 主要步骤：
  1. 生成多帧微泡随机位移轨迹并加噪。
  2. 高斯滤波平滑，每帧阈值化得到二值图。
  3. 连通域分析，使用区域像素均值作为检测位置。
  4. 用欧氏距离构建代价矩阵，匈牙利算法最小化匹配代价。
  5. 绘制每帧跟踪结果并导出 bubble_tracking1.gif。
- 适用场景：微泡数量稳定、帧间位移小，且不希望引入复杂运动模型时。

### tra_2.py
- 方法：阈值分割 + 连通域质心 + KMeans 聚类。
- 主要步骤：
  1. 生成多帧微泡轨迹并加噪。
  2. 高斯滤波平滑，阈值化后提取连通域质心。
  3. 使用 KMeans 将检测到的位置聚类为跟踪结果。
  4. 绘制每帧结果并导出 bubble_tracking2.gif。
- 特点：用聚类代替严格一一匹配，适合做演示或粗略聚合，但不保证轨迹身份一致性。

### tra_3.py
- 方法：滤波方法对比 + KMeans 跟踪。
- 主要步骤：
  1. 生成多帧微泡轨迹并加噪。
  2. 对同一帧使用高斯/中值/均值滤波，生成对比 GIF（filter_comparison.gif）。
  3. 选用高斯滤波结果执行阈值分割与连通域质心提取。
  4. 使用 KMeans 聚类得到跟踪位置，并导出 bubble_tracking3.gif。
- 特点：额外提供滤波效果对比，便于观察不同滤波对后续跟踪的影响。

### tracking_dl.py
- 方法：ConvLSTM 时空模型预测微泡热力图 + 局部峰值检测。
- 主要步骤：
  1. 生成合成多帧序列并加入噪声。
  2. 使用 ConvLSTM 进行时序建模并回归每帧热力图。
  3. 对热力图做局部峰值检测得到微泡位置。
  4. 输出 bubble_tracking_dl.gif。
- 特点：利用时间上下文提高鲁棒性，适合作为深度学习跟踪方案的最小演示。

## 对比分析
- 跟踪策略：tracking_1 使用匈牙利算法做一对一匹配，强调轨迹身份一致性；tra_2 与 tra_3 采用 KMeans 聚类，更像帧内聚合，轨迹连续性不保证。
- 预处理差异：tracking_1 与 tra_2 仅使用高斯滤波；tra_3 额外对比高斯/中值/均值滤波，提供滤波效果参考。
- 输出文件：tracking_1 输出 bubble_tracking1.gif；tra_2 输出 bubble_tracking2.gif；tra_3 输出 filter_comparison.gif 和 bubble_tracking3.gif；tracking_dl 输出 bubble_tracking_dl.gif。
- 适用场景：tracking_1 适合微泡数量稳定、帧间位移较小的跟踪示例；tra_2/tra_3 更适合作为演示或对比实验的简化方案；tracking_dl 适合时序信息更重要、希望引入学习能力的场景。

## 优缺点
### tracking_1.py
- 优点：一对一匹配，轨迹身份一致性更强；实现简单直观。
- 缺点：只用距离匹配，易受遮挡/漏检影响；缺少速度或运动模型，复杂运动时易错配。

### tra_2.py
- 优点：流程简单，聚类对检测数量波动更“宽容”；运行成本低。
- 缺点：聚类中心不对应真实个体轨迹，无法保证跨帧一致性；KMeans 对初始化和簇数敏感。

### tra_3.py
- 优点：提供滤波对比，便于观察预处理对检测与跟踪的影响。
- 缺点：跟踪逻辑与 tra_2 相同，轨迹一致性不足；额外滤波与可视化增加计算开销。

### tracking_dl.py
- 优点：能够利用时序上下文抑制噪声与误检；可扩展到更复杂的真实数据。
- 缺点：需要训练与依赖深度学习框架；对数据量和标注质量敏感。

## 改进方向
- 引入运动模型（如卡尔曼滤波）并结合门控距离，提升匈牙利匹配鲁棒性。
- 使用更稳健的检测（自适应阈值、局部极大值、PSF 拟合）减少漏检/误检。
- 在 KMeans 方案中加入时间连续性约束，或改用简单的最近邻/JPDA 关联。
- 增加“轨迹生命周期”管理（新生/消失/遮挡恢复），避免目标数量变化导致的漂移。
- 为 tracking_dl 引入真实数据集、数据增强与更合理的损失（如 focal/heatmap 损失），提升泛化能力。
